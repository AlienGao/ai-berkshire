## 第二步：生意本质分析 — 段永平"对的生意"

### 一句话定义

晶泰控股是一门**用AI+量子物理+机器人自动化替代传统人工实验的药物研发外包生意**，正从"卖服务"（CRO）向"卖平台+分成"（平台型）转型，并试图把同一套技术复制到新材料、新能源（AI4S）领域。

### 收入漏斗分析（FY2025，亿元RMB）

```
[客户合作项目：全球前20大药企中17家，客户数+62%，复购率>75%]
    │ × 货币化：服务费 + 里程碑付款 + 销售分成
[营收 8.03亿]
    │ - 直接成本：机器人实验室运营、算力、人工
[毛利 5.59亿（毛利率69.7%）]
    │   ⚠️ 剔除DoveTree首付款后核心经营毛利率仅~43.5%
    │ - 研发开支 5.69亿（+36.1%）
    │ - 销售及管理费用（估2-3亿，未精确披露）
[核心经营性亏损（估-2~-4亿，经营性亏损较2024扩大）]
    │ + DoveTree首付款 3.65亿（一次性）
    │ + 金融资产公允价值变动 5.14亿（非现金）
[净利润 1.35亿（年内利润）/ 1.24亿（归母）/ 2.58亿（经调整）]
    │ - 资本支出、股权激励等
[自由现金流：负（仍处烧钱阶段，靠融资维持）]
```

**漏斗关键结论**：
1. **从顶层到净利，转换高度依赖"一次性大单"**——DoveTree首付款一笔就贡献了3.65亿（占收入45%），这3.65亿直接从顶层穿透到利润层，几乎没有成本
2. **剔除大单后的真实生意质量**：核心经营毛利率43.5%（仍算健康），但核心经营层面**尚未盈利**，研发投入（5.69亿）超过经常性毛利（8.03-3.65）×43.5%≈1.9亿
3. **漏斗最底层的自由现金流为负**——这才是芒格式问题所在：这门生意目前靠融资输血，不是靠自我造血

### 商业模式画布

| 维度 | 分析 |
|------|------|
| 收入模式 | 服务费（短期）+ 里程碑付款（中期、大额但不规律）+ 销售分成（长期、尚未兑现） |
| 客户群体 | 全球Top 20药企中17家 + 生物科技公司 + 跨界（晶科能源、巴斯夫、中石化） |
| 核心产品 | ID4平台（AI模型集群+300+机器人工作站+数据闭环）；2026年7月发布XtalPi Science平台+Genius Agents |
| 价值主张 | 药物发现周期从3-5年压缩至约18个月；AI4S把AI+机器人能力复制到材料、能源 |
| 复购逻辑 | 平台锁定+数据积累 → 复购率>75%；但大额里程碑收入天然不规律 |

### 生意质量问题：2026H1给出了第一个真实答案

5月报告曾假设"DoveTree第二笔4,900万美元"到账与否是关键变量。**最新数据修正了这一假设**：实际到账的是**1,900万美元**（2026年5月，合计到账7,000万美元），4,900万美元后续付款**状态未确认**。

2026H1盈利预警揭示的真相：
- **表观收入 -23%~-27%**，因为2025H1计入了DoveTree首付款5,100万美元高基数
- **但内生收入≥2.5亿元（+65%）、AI4S收入≥1.8亿元（+120%）**——底层业务确实在增长
- **归母亏损2.15-2.75亿元**，研发开支+50%

**段永平式追问**：这门生意好在哪？如果只能用一句话描述，是什么？

> **回答**：这门生意好在"AI+机器人平台+数据"理论上能形成正反馈，且已开始向材料、能源复制（AI4S）。但坏也坏在这里——它至今是靠"里程碑大单+外部融资"撑起来的高投入平台生意，**经常性业务的自我造血能力在2026H1仍未得到证明**。好生意的特征是"千百个客户排队付钱"，而晶泰现在是"几个大客户付大钱，但钱到账时间不规律"。

**客观事实**：2026H1由盈转亏，首次完整检验了"盈利可持续性"——结果不及预期。内生增长真实（+65%），但被研发投入加速（+50%）和一次性收入断档双重对冲，报表层面重新亏损。

## 第三步：护城河评估 — 巴菲特"经济护城河"

### 五类护城河逐一验证（更新版）

| 护城河类型 | 评估 | 评分 | 证据（2026年更新） |
|-----------|------|:--:|------|
| **技术/专利壁垒** | 中等偏强 | ★★★☆ | 量子物理+AI+机器人三位一体，300+机器人工作站；XtalFold Ultra升级（抗原-抗体预测准确率+10pct）；但英矽智能已将其生成式AI药物推入III期、Isomorphic获$2.1B融资——**纯AI路线的技术追赶在加速** |
| **转换成本** | 中等 | ★★★ | 客户项目数据沉淀在平台，复购率>75%；但客户通常同时与多家合作，英矽等提供替代 |
| **规模效应** | 潜在 | ★★★ | 机器人自动化+数据积累形成规模优势；AI4S跨界（晶科、巴斯夫）拓宽规模应用面 |
| **网络效应** | 弱 | ★★ | 非双边市场，客户之间无直接互动 |
| **品牌/定价权** | 初步 | ★★★ | 辉瑞盲测历史、礼来/DoveTree/JW制药大单背书；2026年6月新签超4亿美元GPCR合作证明头部客户认可 |

### 护城河趋势判断

**过去2年**：护城河在**变宽但竞争也在变强**。正向：AI4S跨界开辟新战场（材料、能源是纯AI药物公司没有的能力），XtalPi Science平台生态联盟（26家机构）增强平台属性。负向：英矽智能（港股上市、H1收入$1.02-1.06亿、盈利、III期管线）已是更强的纯AI对手；Isomorphic获$2.1B弹药。

**未来5年预判**：
- **乐观**：AI4S成为第二增长曲线，机器人湿实验闭环壁垒因数据+物理资产加深
- **悲观**：英矽/Isomorphic证明"纯AI无需重资产机器人"也能走通，晶泰的重资产投入反而成为负担

### 关键不确定性（2026年新增）

1. **英矽智能的正面验证反噬**：英矽Rentosertib是全球首个生成式AI药物进入III期（2026年7月）。这**验证了行业，但抢走了晶泰的"AI药物第一人"叙事**。如果英矽率先获批，市场会问：为什么投晶泰而不是投英矽？
2. **机器人护城河的双刃剑**：300+工作站是差异化，但也是高资本开支。纯AI竞争对手（英矽、Isomorphic、Chai）无需重资产就获高估值，晶泰的重资产投入必须在"交付实打实分子"上兑现
3. **AI4S跨界的真实规模**：晶科能源合资、巴斯夫工作站是方向正确，但收入贡献尚小（AI4S FY2025仅2.65亿）

### 巴菲特式追问

> 10年后这条护城河还在吗？什么能摧毁它？

**回答**：如果护城河存在，它不在"AI算法"（这个2-3年就会被追平），而在"机器人湿实验+数据闭环+AI4S跨行业复用"——这是纯AI公司没有的。但能摧毁它的有三条路径：① 英矽/Isomorphic证明重资产湿实验不必要；② AI4S跨界被深势科技等本土基础设施玩家抢走；③ 大客户（礼来/英矽式合作）把AI能力内部化，不再外包。**坦白说，10年后护城河还在的概率<50%**。

### 空方核心论点（必须认真对待）

1. **估值锚问题**：晶泰市值$45.7亿，是Schrödinger（$14亿）的3倍+，但英矽智能（H1收入$1.02-1.06亿）收入已超晶泰（FY2025收入$1.1亿）的全年水平且已盈利。**市场给晶泰的估值溢价缺乏基本面支撑**
2. **"盈利"是幻觉**：FY2025的1.24亿归母净利包含3.65亿首付+5.14亿公允价值变动，剔除后经营亏损；2026H1已现形（亏损2.15-2.75亿）
3. **烧钱无底洞**：上市2年融资~90亿港元（3次配股+CB），现金仍在高消耗（研发+50%），何时自我造血无时间表
4. **4,900万美元付款悬而未决**：DoveTree合同最大的"确定性"表述可能被证伪
