### AI 研究局限性声明

1. **本报告的核心分歧点无法用公开资料解决**：公司口径 8 月单月 MaaS 收入 1.33 亿美元（约8.93亿元人民币），**超过整个上半年的 MaaS 收入（8.25亿元人民币）**；而上半年 API 业务收入年化约 **2.46 亿美元**，与 16 亿美元 ARR 相差约 **6.5 倍**。三个口径互相矛盾，公开资料中找不到可独立验证的支撑。本报告将各口径并列呈现，**不替读者做选择**。

> 智谱刚刚交出了中国大模型创业公司有史以来最漂亮的一份收入表——**半年收入 9.54 亿元超过 2025 全年，API 收入增长 27 倍，API 毛利率首次转正**；同一份报表里也写着这门生意最残酷的真相——**整体毛利率从 50.0% 腰斩到 26.4%，烧钱速度两个月内加速近 10 倍，公司在 9 个月内以越来越低的价格卖出了 750 亿港元的股票**。股价从 6 月高点跌掉 75.8% 之后，估值已从"荒谬"回到"需要乐观情形成立"——但 2027 年 1 月约 40% 解禁、连续折价稀释、毛利率结构性下探三道关卡尚未通过。**结论：从"绝对回避"下调为"可跟踪的观察标的"，维持零仓位。**

## 三、前置：AI 研究偏见自查

| 自查问题 | 本次研究的回答 |
|----------|---------------|
| 我的"确定性"感受来自生意本质，还是资料数量？ | **来自资料数量**。公司刚发中报，数据丰富，容易产生"看懂了"的错觉。但真正的关键变量（订阅留存、经营现金流、客户质量）**全部缺失**。 |
| 如果把资料量减少一半，结论会变吗？ | **不会**。核心结论（生意质量中等偏上、价格仍需乐观情形、筹码结构是最大变量）在 7 月只有招股书时就已得出，中报只是强化了"收入真实爆发 + 毛利率结构性下探"这对矛盾。 |
| AI 输出是否与市场共识雷同？ | **部分雷同，部分相反**。与卖方共识（中金1,572、摩根大通2,000港元）相反；与杰富瑞（1,183.79、持有）、高盛（中性、1,880港元）方向一致。本报告的信息优势不在结论，而在**对"ARR 与确认收入 6.5 倍落差"的独立质疑**。 |
| 是否存在"资料多但生意本质差"被高估的可能？ | **存在且是主要风险**。API 毛利率 24.6% 意味着每 1 元收入要付 0.75 元算力成本——这是**硬件生意的成本结构，软件生意的估值**。 |

### 本次研究对前次结论的三处修正

1. **董事长身份更正**：前次报告称"CEO/董事长：张鹏"——**不准确**。**董事长为刘德兵**（分管战略与资本），**张鹏为 CEO/总经理**（分管商业化与工程），唐杰任首席科学官。据智谱A股上市辅导备案报告，**唐杰与刘德兵为共同实际控制人，合计控制 36.9647% 表决权**；唐杰直接持股 **7.4081%**，刘德兵直接持股 **0.2554%**。（前次报告写"唐杰6.02%、张鹏0.09%"，应予更正。）
2. **"7月7-8日约11.6%解禁"口径有误**：11.6% 是**中金公司研报的预估口径**；公司实际披露的解禁数量为 **2,568.16万股，占总股本 5.76%**。
3. **"现金跑道8年以上"判断被证伪**：7 月配售 314 亿港元后，本系列曾称现金跑道延长至 8 年以上。**事实是：50 天内动用 109.55 亿港元（日均 2.19 亿），月均消耗从 IPO 阶段的 6.12 亿港元加速至约 65.7 亿港元，加速近 10 倍。** 按此速度，9 月融资后的约 706 亿港元仅够约 10.8 个月。**前次判断在不到两个月内失效，这是本次研究最重要的方法论教训——对一家把现金转化为算力预付款的公司，"在手现金÷历史烧钱率"是最不可靠的跑道估算方式。**

## 五、生意本质分析——段永平"对的生意"（第二步）

### 5.1 用一句话定义这门生意

> **把算力加工成智能，按 token 零售给开发者，按项目批发给政府。**

这句话里藏着两个完全不同性质的生意，而 2026 上半年发生的事，是**两者的比例在一年内被彻底颠倒**。

### 5.2 收入结构：一年之内换了一次血

| 分部 | 2025H1 | 占比 | 2026H1 | 占比 | 同比 |
|------|--------|------|--------|------|------|
| 开放平台及API | 0.291亿 | 15.25% | **8.252亿** | **86.51%** | **+2,735.7%** |
| 企业级通用大模型 | 1.476亿 | 77.33% | 0.670亿 | 7.02% | **-54.6%** |
| 企业级智能体 | 0.137亿 | 7.18% | 0.556亿 | 5.83% | +304.4% |
| 技术服务及其他 | 0.005亿 | 0.26% | 0.061亿 | 0.64% | +1,166.7% |
| **合计** | **1.909亿** | 100% | **9.539亿** | 100% | +399.7% |

**一年前，智谱是一家"卖项目的公司"；今天，它是一家"卖 token 的公司"。** 前次报告称其为"从劣质生意向较好生意迁移"，中报把这个判断推进了一步——迁移速度远超预期，但**方向未必是"较好"**。

### 5.3 段永平式追问：这门生意好在哪？

**支持"好生意"的证据（真实且罕见）：**

1. **量价齐升**：API 平均售价 +101%，同期 Token 调用量 +40 倍。在任何生意里，量价齐升都是最强的需求信号——客户不是因为便宜才来的。
2. **单位经济在改善**：单位 token 推理成本 -80%，算力乘数（每 1 元算力产出的 API 收入）+14 倍。**成本下降速度快于价格**，这是毛利率改善的机械条件。
3. **API 毛利率转正**：从 2025H1 的 -0.4% 提升至 24.6%，一年提升 25 个百分点。
4. **客户使用深度爆发**：前十大客户日均调用量 +98 倍，付费 DAU +603%——这是"用起来了"而非"买回去了"的信号。

**反对"好生意"的证据（同样真实）：**

1. **整体毛利率腰斩**：50.0% → 26.38%。增长最快的业务（API，占收入 86.5%）恰恰是毛利率最低的（24.6%）。**收入结构越优化，账面毛利率越难看。**
2. **管理层自己承认没有底**：业绩会明确表示，若 API 占比继续上升，整体毛利率将被持续"向下拉扯"。
3. **24.6% 的毛利率意味着什么**：每 1 元收入要付出 0.75 元算力成本。这是**硬件分销商的成本结构**。作为对照，DeepSeek 的 API 毛利率是 **82.9%**、整体毛利率 **44.6%**；商汤整体毛利率 **41.4%**；MiniMax **17.9%**（但其收入结构不同，B端语音/视频API 毛利率曾达69.4%）。
4. **规模不经济**：销售成本 +635.4%，远超收入增速的分母效应；研发 21.31 亿元 = 收入的 **223%**。收入翻四倍，经调整亏损反而扩大 12.1%。

**结论：智谱目前做的是一门"增长极好、单位经济极差"的生意。** 它证明了模型层能收到钱，但还没证明能留下钱。段永平的标准是"生意的本质是差异化"，而 24.6% 的 API 毛利率说明：**在 token 这个品类里，智谱的产品差异化程度，目前只值 25 个点的毛利。**

**但反面同样重要**：从 -0.4% 到 24.6% 只用了一年，且成本端（国产芯片推理、单位成本 -80%）仍在快速改善。斜率比水平更能说明未来——这正是需要用后续季报验证的第一指标。

### 7.4 芒格式追问：我最可能在哪里犯错？

> **最可能的错误，是把"收入爆发"误读为"商业模式验证"。**

**反方（我可能错在另一个方向）**：单位 token 成本一年降 80% 且仍在降，国产算力规模化（10万卡）会继续压低成本；如果成本下降持续快于价格下降，毛利率从 26% 向 50% 的爬坡可能在 2-3 年内发生——届时这门生意的性质会改变。**这个可能性是真实的，也是本报告维持"跟踪"而非"拉黑"的原因。**

### 9.2 但利润沉淀在哪一层？——当前 100% 在算力层

| 环节 | 利润状况 |
|------|---------|
| **内存/HBM** | HBM4 成本从 HBM3e 的 17-18 美元/GB 升至 **31-32 美元/GB**；2026Q2 DRAM 合约价 +58-63%；英伟达毛利率 Q2 75% → Q4 预计降至 71-72%（议价权转向内存厂） |

### 9.3 关键变量：DeepSeek 何时需要赚钱？

前次报告已指出，DeepSeek 因"不依赖模型收入盈利"而使行业理性定价不存在。**本期有两个新事实：**

1. **DeepSeek 自身融了 510 亿元（首轮）+ 二轮投前 5,000 亿元**，且**首轮披露了 API 毛利率 82.9%、整体 44.6%、前7月收入 4.75 亿元**——说明它也在准备资本化路径（已委托中信证券筹备科创板，目标 2027 年挂牌）。
2. **2026-09-10 DeepSeek V4.1 Flash 发布，每百万 token 不到 1 美分**，富瑞称其 Agentic Benchmark 表现**优于 GLM-5.3 与 Kimi K3**，价格较 GLM-5.3 的 cache hit/输入/输出分别低 **98%/75%/71%**。当日智谱、MiniMax 一度跌超 8%。

**这对智谱是双刃剑**：坏消息是价格战仍在升级；好消息是 DeepSeek 若走向 IPO，其定价行为将从"使命驱动"转向"利润驱动"，行业理性化才有可能。

### 9.4 李录式追问：20年后回看，智谱是"标准石油"还是"3Com"？

**大概率是 3Com，而非标准石油。**

标准石油的特征是：控制了不可复制的稀缺环节（管道+炼油产能），并能把成本优势转化为行业集中度。智谱的稀缺性在**信创身份**（真实但属政策租金），而非在**技术或规模**（两者均可在 3-6 个月/2-3 年内被追平）。

**但要留一个窗口**：如果 Coding Plan / Agent 订阅真的建立了工作流级别的切换成本，模型层可能出现类似"数据库厂商"的稳定格局（1-2 家拥有定价权）。这是智谱唯一可能成为"标准石油"的路径，**而这个路径的验证数据（订阅留存率）至今从未披露。**

## 十二、总结

智谱在 2026 年上半年完成了一次教科书级的收入结构转换：从卖项目到卖 token，API 收入增长 27 倍，首次实现 API 毛利率转正，量价齐升——这是中国大模型创业公司交出的最接近"商业自洽"的成绩单。

但同一份报表也写明了代价：整体毛利率从 50.0% 腰斩至 26.38%，经调整亏损扩大 12.1%，烧钱速度两个月内加速近 10 倍，公司在 8 个月内以越来越低的价格卖出了超 750 亿港元的股票。**股价从 2,980 港元跌至 721 港元（-75.8%）不是市场犯错，是市场把 6 月时预支的乐观全额收回。**

**当前 3,357 亿港元市值下的核心矛盾，已经从"价格荒谬"转变为"生意清晰度不足"**：
- 若相信 ARR（16亿美元），P/ARR 26.75 倍，与 OpenAI 同区间——**不贵**
- 若相信确认收入（H1年化），PS 150.66 倍（TTM 193.26 倍）——**仍然极贵**
- 若相信卖方 2026E（62-67亿元），PS 42.82-46.36 倍——**在可辩护区间上沿**

三个口径给出三个完全不同的答案，而这个分歧无法用公开资料解决——**H1 的 API 收入年化约 2.46 亿美元，与 16 亿美元 ARR 相差 6.5 倍。这本身就是"不买"的充分理由。** 价值投资不需要在模糊地带下注。

**结论：回避，零仓位，保留观察。** 从 7 月的"绝对回避"下调为"可跟踪的观察标的"。日历上只需要记三个日期：**2026年10-11月（三季报验证毛利斜率）、2027年1月8日（约40%解禁大考）、以及第一次披露订阅留存率的那一天。**

> **智谱依然是中国大模型创业公司里质地最好的一家，也依然处在它上市以来最好的一次价格区间里。这两句话同时为真——而第二句成立的前提，是那 9.5 亿元的"单月收入"，真的存在。**
