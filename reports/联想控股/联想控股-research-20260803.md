## 0. AI研究偏见自觉（前置声明）

### 信息丰富度评级：**B级（信息适中）**

联想控股2015年港上市，券商覆盖有限（无深度一致预期模型）、多数报道集中于子公司联想集团，NAV测算多散见于雪球等社区而非权威机构。资料适中意味着**AI可能用"合理推测"填补空白**——本报告所有推算数据一律标注 `[估计]` 并区分"有据推算"与"凭空填充"。

**本研究的应对策略**：锁定三个非共识问题：
1. **折价是"错价"还是"正确的定价"？** 市场给联想集团持股市值2.76倍于联想控股市值，其余资产被定价为负610亿港元——这是市场疯了，还是市场看透了"纸面资产无法变现"？
2. **2026H1盈喜（净利预增≥186%）是拐点还是脉冲？** 归母利润从2023年-38.7亿到2026H1≥20亿，是盈利能力修复还是投资浮盈兑现？
3. **控股公司折价会收敛吗？** 历史十年折价50-70%，现在78%——折价收敛需要什么条件？港股的复星/中信们收敛过吗？

**关键提醒**：联想控股是**投资控股平台**，不是单一运营实体。用常规PE框架分析它会得出"30倍PE太贵"或"0.55倍PB太便宜"两个同样失真结论——正确框架是 **NAV（每股净资产价值）折价法**。

**偏见自查清单**：
- [x] 确定性来自资料量还是生意本质？→ 本报告确定性高的是"折价数据本身"（可验算），低的是"折价收敛"（本质上是治理与变现问题，资料无法回答）
- [x] 资料量减半结论会变吗？→ NAV测算部分会变（依赖雪球/花旗转引的估计值），财报部分不变
- [x] 与市场共识雷同吗？→ 看多逻辑（白送论）与散户社区高度一致，故第四模块重点拆解"白送论"的陷阱
- [x] 是否存在"资料少但本质好"？→ 不存在，这家公司是"资料适中但本质存疑（多元化控股）"的典型

## 2. 生意本质分析 — 段永平"对的生意"

### 2.1 一句话定义

**联想控股不是一门生意，是五门生意的打包加一个投资平台：它同时运营IT（联想集团）、新材料（联泓新科）、食品（佳沃）、银行（BIL）四门实体生意，外加君联资本/联想之星/弘毅三大基金做投资孵化——核心资产是持股32.34%的联想集团。**

### 2.2 收入结构拆解（2025年）

**结构本质**：联想集团一家贡献92.5%收入、约85%的归母利润；其余资产合计归母贡献为**负**（佳沃-8.63亿+投资-14.77亿被BIL+14.83亿部分抵消）。

### 2.3 商业模式画布

- **收入性质**：混合——联想集团的硬件销售（周期性）+ 银行利息（金融）+ 基金投资收益（波动性）+ 联泓/佳沃制造业
- **核心特征**：**归母利润远小于合并利润**。2025年含少数股东净利97.99亿，归母仅10.61亿——差额86亿主要归属联想集团的少数股东（联想控股仅持联想集团32%，其余68%利润不归它）
- **价值承载**：联想控股的价值不在利润表，在资产负债表——它是一堆股权资产的"打包壳"

### 2.4 5年盈利能力趋势（归母口径）

**⚠️ 关键观察**：这是**极低的归母回报率**。5年累计归母净利约42亿，但2023年一次巨亏-38.7亿（投资板块拖累）几乎吃掉全部。ROE中枢1-2%，远低于资金成本。**作为"投资公司"，资本配置回报不合格。**

### 2.5 段永平式追问

> **"这门生意好在哪？如果只能用一句话描述，是什么？"**

段永平的第一反应会是：**这根本不是一门生意，我无法用一句话描述它好在哪**。多元化控股公司违反他的"能力圈"原则——没有一个管理团队能同时把IT、材料、食品、银行、股权投资五件事做好。联想集团是好生意（全球PC第一+AI服务器高增），但联想控股持有它32%且无法控制其全部利润；其余资产五年累计亏约134亿。

**生意本质评分：★★☆☆☆（2/5）** — 底层资产有亮点（联想集团/BIL），但"盒子"本身是五门生意的杂烩，归母回报率1.9%，不是段永平定义的"对的生意"。

## 3. 护城河评估 — 巴菲特"经济护城河"

**先分清两层**：联想控股的护城河 = 底层资产的护城河，而非"盒子"本身的护城河。

| 层面 | 资产 | 护城河评估 |
|---|---|---|
| 底层资产 | **联想集团** | ★★★★☆ 全球PC份额第一、AI PC全球第一（2025Q4 Windows AIPC）、AI服务器三位数增长、品牌+渠道+生态。但PC是周期性成熟行业，AI服务器面对英伟达/超威等强敌 |
| 底层资产 | **BIL卢森堡银行** | ★★★☆☆ 欧洲银行牌照+财富管理，AUM 477亿欧元、资本充足率13.86%。区域性强，增长天花板有限 |
| 底层资产 | **君联资本/联想之星/弘毅** | ★★★☆☆ 中国顶级VC/PE品牌之一，管理资本超2,000亿，中科院成果转化通道是稀缺资源。但基金业绩靠退出时点，波动大 |
| **盒子本身** | **联想控股** | ★☆☆☆☆ **无护城河**——它只是持股壳，不创造任何独立价值；持股比例不足以控制联想集团（仅32%，其余股权分散/少数股东） |

### 3.1 护城河的关键问题：持股比例意味着什么？

联想控股持联想集团32.34%。这个比例**不足以并表控制全部利润（归母只有少数），也不足以主导联想的战略**。巴菲特框架下这是致命问题：**你无法把持股市值的NAV变成自己的现金流**——因为你无法出售大宗股权（会砸盘+可能受限售），也无法要求联想集团全额分红。

### 3.2 巴菲特式追问

> **"10年后这条护城河还在吗？什么能摧毁它？"**

底层资产（联想集团AI PC/服务器、BIL牌照）10年后大概率还在；但**联想控股这个"盒子"的护城河从来就不存在**。真正的问题是：10年后这个盒子还有存在意义吗？如果资本配置持续无效（ROE 1.9%），它要么被私有化/清算，要么继续以折价交易——**盒子不创造价值，护城河无从谈起**。

**护城河评分：★★☆☆☆（2/5）** — 底层资产有护城河，但投资者买的是"盒子"，而盒子无护城河且无法兑现底层资产价值。

### 4.1 这家公司可能失败的所有路径

| 失败路径 | 概率 | 影响 | 说明 |

| **折价陷阱/价值黑洞** | 高 | 高 | "白送论"最大陷阱：纸面NAV≠可变现现金。联想集团持股无法自由大宗出售（市场承接力不足+可能触发披露/限售），折价可能永远不收敛 |

| **地缘政治** | 中低 | 高 | 美国对华科技管制冲击联想集团（AI芯片/服务器出口受限）→ 间接打击联想控股NAV |

### 4.2 历史类比

联想控股最像**复星国际（0656.HK）**：同为多元化控股平台，长期处于0.2-0.5倍PB、大额NAV折价，折价从未有效收敛。芒格框架下最贴切的类比是**"控股公司折价是理性定价而非市场错误"**——市场惩罚的是：无法变现的纸面价值 + 双重征税 + 管理层代理成本 + 信息不透明。

**反例警示**：历史上NAV折价大幅收敛的控股公司，几乎都靠**主动价值释放**（分拆上市、私有化、大额回购、特别分红）实现。联想控股至今无回购记录、2023-24零派息——**它没有主动收敛折价的历史意愿**。

### 4.3 偏误自查

- **锚定效应**：散户锚定"联想集团持股市值=控股市值2.76倍"，得出"其余资产白送"——这是对"可变现性"的锚定错误
- **叙事偏差**："中科院系+AI重估"叙事让盈喜日的+11.9%看起来像拐点，但归母利润仍只有10.61亿量级
- **幸存者偏差**：只看到联想集团AI服务器三位数增长的亮点，忽略五年亏损134亿的非联想业务的持续失血

### 4.4 芒格式追问

> **"我最可能在哪里犯错？聪明人为什么不买/做空这家公司？"**

我最可能犯的错是**把"便宜"当"安全边际"**——0.55倍PB、75% NAV折价看似深度低估，但如果折价永远不收敛，它就不是错价而是"正确的定价"。聪明人不买的原因：① 无法推动价值释放（无实控人+持股不足）② 归母ROE 1.9%证明资本配置无效 ③ 母公司现金流为负 ④ 无回购无稳定分红。**这是典型的"价值陷阱"特征：越便宜越没人买，因为没人有办法把NAV变成现金。**

**风险评分：★★☆☆☆（2/5，风险高）** — 核心风险不是"亏损"，而是"折价永不收敛"的结构性风险+联想集团单一依赖+治理顽疾。
