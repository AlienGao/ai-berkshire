### 商业模式画布

| 要素 | 分析 |
|------|------|
| 收入模式 | 一次性零售销售为主，非订阅/复购模式；复购依赖门店动销与上新 |
| 产品属性 | 生活好物（日用品、美妆、配饰、电子配件）+ 潮玩（TOP TOY）+ IP 联名商品 |
| 客户 | C 端大众消费者（中国 + 海外 112 国），价格带主力 $5-25 |
| 渠道 | 线下门店（集团 8,565 家 @2026-03-31）+ 线上电商；直营+零售合伙人+分销混合，海外直营化推进中 |
| 供应链 | 超 1000 家供应商，规模化采购 + 极短上新周期，"供应链效率"是核心 |
| 竞争壁垒来源 | 规模采购成本优势 + 全球渠道网络 + 联名 IP 流量（非自有 IP 粘性） |

### 生态粘性 / 客户锁定强度：★2（弱）

消费者对"名创优品"这个品牌本身几乎没有忠诚度——他们忠诚的是"便宜 + 好看 + 联名 IP"。这决定了：
- 客户转换成本 ≈ 0（隔壁开一家更便宜/更有 IP 的店，客流立刻转移）
- 复购靠持续上新驱动，而非品牌锁定
- **段永平式追问**：如果名创优品明天涨价 30%，销量会掉多少？——答案是"会掉很多"，这说明定价权弱，生意本质是"效率生意"而非"品牌生意"。

### 经营杠杆分析

- **正面**：轻资产零售合伙人模式（中国内地 4,552 家零售合伙人 vs 直营仅 15 家），规模扩张边际成本低；FY2025 经营利润 33.03 亿元、经调整 EBITDA 49.60 亿（23.1% 利润率）
- **反面**：营收 +26% 但经营利润 -0.38%；26Q1 销售及分销开支 +44.0%（直营门店相关租金/折旧/薪酬 +34.6%）——**直营化扩张正侵蚀短期利润率**。市场用 H1 预告"低于指引"的经调整利润对这个趋势投了反对票

### 段永平式追问总结

> **这门生意好在哪？** 好在"全球扩张 + 极致供应链 + 高频上新"的组合，能在全球 112 国复制；坏在"没有品牌定价权 + 没有客户锁定"，本质是渠道效率生意，赚的是辛苦钱、管理钱，不是模式钱。

## 模块二：护城河评估 —— 巴菲特"经济护城河"

### 五类护城河逐一验证

| 护城河类型 | 验证结果 | 评级 |
|-----------|---------|------|
| 品牌/定价权 | 弱。美国价格带 $5-25，叶国富称关税/通胀"都是机遇"，但无证据显示提价不损失销量；45% 毛利率主要靠供应链效率而非品牌溢价 | ★2 |
| 转换成本 | 极低。消费者随时可切换到名创/无印/泡泡玛特/拼多多白牌，无任何锁定 | ★1 |
| 网络效应 | 无。零售不存在"用户越多产品越好"的网络效应 | ★1 |
| 规模效应 | 中强。超 1000 家供应商 + 全球 8,565 家门店的采购规模带来成本优势；但这一优势拼多多/泡泡玛特同样具备，且后者在 IP 端更强势 | ★4 |
| 技术/专利壁垒 | 弱。零售运营模式可复制；唯一潜在壁垒是"IP 联名资源网络"和"全球本地化运营能力" | ★2 |

### 护城河综合评级：★2.5（窄）

**关键判断**：名创优品的护城河是"窄而具体"的——
- **真实存在**：全球 112 国的渠道网络 + 规模采购成本 + 跨文化本地化运营能力（海外收入占 MINISO 品牌 44.2% 且 +29.3%，已在海外立足，这比大多数中国零售公司强）
- **并不宽**：本质是"执行力的护城河"而非"模式的护城河"。任何有钱、有执行力、有供应链资源的玩家理论上都能复制

### 护城河趋势判断

- **过去 5 年**：变宽。从"中国十元店"进化为"全球 112 国零售网络"，海外收入占比从个位数提升到 44.2%
- **未来 5 年**：关键变量是 **IP 转型是否成功**。若自有 IP 从 16 个增长到几十个并跑出爆款，护城河显著变宽（从效率护城河 → 内容/IP 护城河）；若 IP 转型失败，护城河停留在"窄"水平，长期竞争将非常吃力

### 巴菲特式追问

> **10 年后这条护城河还在吗？什么能摧毁它？**
> - 摧毁路径 1：AI 电商/即时零售进一步压缩线下零售（如果消费者都去 Temu/Shein 买 $5 商品，线下门店的价值下降）
> - 摧毁路径 2：泡泡玛特或其他 IP 玩家向"生活方式全品类"扩张，正面竞争
> - 摧毁路径 3：IP 联名模式退潮（消费者对"联名款"疲劳），而自有 IP 又无法补位
> - 护城河仍在的判断：全球 112 国渠道 + 供应链是重资产、慢构建，短期难被摧毁；但"宽"与"窄"的差距在于 IP，这是最大变数

### 历史类比

- **无印良品（MUJI）日本**：同为"生活好物 + 极简设计"零售。MUJI 在 2010 年代因品牌势能下降 + 中国竞争加剧而陷入长年低增长。教训：**"生活方式零售"的品牌势能一旦衰减极难重启**
- **Zara / H&M 快时尚**：同为"上新快 + 供应链快"。Zara 的护城河（垂直一体化供应链）比名创（外部供应商）更深。教训：**供应链快是必要条件，不是护城河**
- **泡泡玛特 vs 名创**：同一个潮玩市场，泡泡玛特 2025 营收 371 亿、净利 130 亿、毛利率 72.1%、LABUBU 单 IP 141.6 亿；名创 TOP TOY 19.16 亿营收、自有 IP 占比 5.7%。**同为"卖 IP"，商业模式质量差距显著**。泡泡玛特卖的是"内容 + 情感"，名创卖的是"联名 + 流量"

### 跨学科分析

- **网络效应理论**：零售无网络效应，增长靠"复利开店"而非"复利用户"，因此增速天花板由渠道承载能力决定，而非由用户自增长决定
- **技术采纳曲线**：IP 潮玩处于"创新者→早期大众"扩散阶段，泡泡玛特已证明需求存在，但名创 TOP TOY 是"跟随者"而非"定义者"
- **竞争博弈**：名创押注"IP 联名 + 大店"，泡泡玛特押注"自有 IP + 高端收藏"，拼多多/Temu 押注"白牌 + 低价"。三线竞争下，名创的"中间地带"（$5-25 联名好物）空间是否够大是核心问题

### 偏误自查

| 偏误 | 本报告检查 |
|------|-----------|
| 叙事偏差 | 警惕"IP 转型成功"的叙事；数据上自有 IP 仅 16 个，占收入比例未披露（估计 <10%） |
| 锚定效应 | 警惕"券商一致目标价 US$19.71-21.73"的锚定；须独立评估 |
| 幸存者偏差 | 只看成功案例（泡泡玛特）会高估 IP 生意成功率；多数零售转型失败是常态 |
| 增长偏差 | +26% 营收增速很亮眼，但要看到归母净利 -54%、经调整净利 H1 转负的现实 |

### 空方核心论点（本报告重点收集）

1. **增收不增利是硬伤**：FY2025 营收 +26.2% 归母净利 -54%；2026 H1 收入 +22-23% 但经调整利润（剔除汇兑）-1~-3%，且**低于公司自己此前的"高单位数增长"指引**——管理层预期落空
2. **永辉是"错误的正确"**：约 63 亿收购一家 2025 年营收 -20.8%、亏损 25.5 亿的超市——典型"抄底心理"，但超市行业是结构性衰退（社区团购 + 电商 + 即时零售三面夹击）。巴菲特会问：**你为什么要买一门正在被技术淘汰的生意？**
3. **自有 IP 缺失**：180+ 合作 IP 中自有仅 16 个。合作 IP（迪士尼、三丽鸥等）的授权费会侵蚀毛利，且无法形成"只有名创能卖"的独占性
4. **估值锚点漂移**：市场对名创的估值在"消费零售（低 PE）"与"潮玩 IP（高 PE）"之间摇摆。当前 PE（TTM）11.2x / 前瞻 7x，说明市场按"零售"定价，并未给 IP 转型买单
5. **直营化烧钱**：26Q1 销售及分销开支 +44%，H1 利润率下滑主因直营扩张 + 市场推广——**增长的质量在恶化**（营收高增靠费用前置堆出）
